# CS4V48 - GenAI and LLM Laboratory

This repository contains lab exercises for the **CS4V48 - GenAI and LLM** laboratory course, covering practical implementations of Generative AI and Large Language Model concepts using pre-trained foundation models, Hugging Face Transformers, diffusion models, and cloud deployment frameworks.

## 📋 List of Experiments

| Ex. No | Experiment Name |
|--------|------------------|
| 1 | Text Generation Using Pre-Trained Foundation Models |
| 2 | Prompt Engineering Techniques for Content Generation, Reasoning and Task Automation |
| 3 | Conversational AI Chatbot Using Transformer-Based Language Models |
| 4 | Text Summarization and Question-Answering System Using Large Language Models |
| 5 | Sentiment Analysis and Document Classification Using Foundation Models |
| 6 | Retrieval-Augmented Generation (RAG) System Using Vector Databases |
| 7 | AI-Powered Code Generation and Debugging Assistant |
| 8 | Image Generation Application Using Diffusion Models |
| 9 | Multimodal AI Application Integrating Text and Image Inputs |
| 10 | Fine-Tuning a Pre-Trained Language Model for a Domain-Specific Application |
| 11 | AI-Based Content Generation System for Text, Image and Multimedia Applications |
| 12 | Deployment and Evaluation of a Generative AI Application Using Cloud-Based APIs and AI Frameworks |

## 🛠️ Technologies Used

- **Python 3.9+**
- **Hugging Face Transformers** — pre-trained models (GPT-2, DialoGPT, BART, DistilBERT, BLIP, CodeGen)
- **PyTorch**
- **Diffusers** — Stable Diffusion for image generation
- **LangChain, FAISS, Sentence-Transformers** — RAG pipeline
- **Gradio** — web app deployment
- **Datasets, Scikit-learn** — fine-tuning and evaluation

## 🚀 How to Run

1. Clone the repository
```bash
   git clone https://github.com/YOUR-USERNAME/Gen-AI-LAB.git
   cd Gen-AI-LAB
```
2. Install dependencies for the relevant experiment
```bash
   pip install transformers torch diffusers gradio langchain faiss-cpu sentence-transformers
```
3. Open the desired experiment's notebook/script in Jupyter Notebook, VS Code, or Google Colab
4. Run the cells/script to see the sample output
